# チャンネル運営者への連絡文（下書き）

**目的は「見てもらって、公開の可否を確認する」ことだけ。** 収益化やリンク設置のお願いは、許可が出てから改めて相談する。

最初の接触で要求を増やすと判断が重くなり、保留されやすくなる。返事のハードルを「はい / いいえ」まで下げるのが狙い。

送り先の候補: 概要欄の「お問合せ」先、お店のInstagram、YouTubeチャンネルの「概要」タブのメールアドレス。

## 送る前のチェック

- [ ] デモURLが開ける状態になっている（限定公開でよい。Netlifyのパスワード保護など）
- [ ] スマホで開いて崩れていないか確認した
- [ ] 冒頭の一言が具体的か（テンプレ感が出ると読まれない）
- [ ] 長すぎないか。この下書きくらいの分量に収める

## 触れないでおくこと

以下は許可が出てから、別の連絡で相談する。

- 収益化（広告、商品への送客）
- 全動画の概要欄にリンクを入れてもらう依頼

ただし**「広告は入れていません」と書いた以上、後から黙って入れるのは不誠実**になる。広告を検討する段階になったら必ず再度連絡する。

## 返事が来なかった場合

2〜3週間待って返信がない場合、「返事がない＝許諾」ではない。公開するかどうかは、抜粋表示と出典明記で引用の範囲に収まっているかという別の判断になる。
