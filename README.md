# recipe-search — 概要欄からさがす（とにかく売れたい中華料理屋）

YouTube チャンネルの全動画の概要欄を取得し、任意のワードで全文検索するための個人用 SPA。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。単一ファイル、依存ゼロ |
| `fetch-videos.mjs` | YouTube Data API で全動画を取得し `videos.json` を生成 |
| `update.ps1` | `videos.json` を更新する（タスクスケジューラ登録用） |

---

## 設計方針

**概要欄はパースせず、そのまま保存して全文検索する。**

以前は概要欄から材料を構造化して抽出し、食材の候補リストから絞り込む方式でした。これをやめた理由:

- 概要欄の書式が動画ごとにバラバラで、パーサーが必ず取りこぼす
- 実際、見出しが `〜材料〜` 形式の動画を丸ごと落としていて、284本中16本しか拾えていなかった
- 機材のアフィリエイトリンク、店舗情報、チャプター、調理の指示文が「食材」として混入し続けた
- 表記ゆれの統合辞書は、別物を同じだと誤判定するリスクを常に抱える（中華の素と鶏ガラスープの素など）

全文検索なら取りこぼしが原理的に起きません。代わりに精度は落ちます（「ネギ」で検索すると雑談回の「ネギ農家さんに会いました」も出る）。これは除外ワードと「ショートを除く」フィルタで運用します。

**動画は一本も捨てません。** ショートも雑談回もすべて取得します。

## 使い方

### 1. API キーを取得

必要なのは **API キーだけ**です。公開データしか読まないので OAuth クライアント ID や同意画面の設定は不要です。

1. [Google Cloud Console](https://console.cloud.google.com/) にログイン
2. 「新しいプロジェクト」を作成
3. 「APIとサービス」→「ライブラリ」→ `YouTube Data API v3` を **有効にする**
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→ **APIキー**
5. 表示されたキー（`AIza...`）をコピー

> 「APIの制限」は手順3で有効化した後でないと選べません。アプリケーションの制限は、ローカルの Node から叩くだけなら「なし」のままにしてください（HTTPリファラー制限を付けるとサーバーサイドから叩けなくなります）。キーは Git に含めないこと。

### 2. データを取得

Node.js 18 以降が必要です。

```powershell
# Windows (PowerShell)
cd H:\ClaudeCode\recipe-search
$env:YOUTUBE_API_KEY="AIza..."
node fetch-videos.mjs --raw raw.json
```

```bash
# macOS / Linux
YOUTUBE_API_KEY=AIza... node fetch-videos.mjs --raw raw.json
```

`--raw raw.json` を付けると API の生レスポンスも保存されます。以降 `videos.json` を作り直すだけなら API を叩かずに済みます。

```powershell
node fetch-videos.mjs --from-raw raw.json   # APIキー不要
```

**クォータ:** 無料枠は 1日 10,000 ユニット。消費は `1 + ceil(動画数/50) × 2` 程度。動画 500 本でも約 21 ユニットです。

### 3. 新しい動画を取り込む（自動更新はされません）

`videos.json` は実行した時点のスナップショットです。動画が投稿されても自動では増えません。更新するには取得しなおします。

`update.ps1` を用意してあります。同じフォルダに `apikey.txt` を作ってキーを1行で書いておけば、あとはこれを実行するだけです。

```powershell
.\update.ps1
```

> `apikey.txt` は Git に含めないでください。`.gitignore` に追加しておくと安全です。

**定期実行したい場合** — Windows のタスクスケジューラに登録します。

1. 「タスク スケジューラ」を開く →「基本タスクの作成」
2. トリガー: 毎日（時刻は任意。深夜など使っていない時間帯が無難）
3. 操作: 「プログラムの開始」
   - プログラム: `powershell.exe`
   - 引数: `-ExecutionPolicy Bypass -File "H:\ClaudeCode\recipe-search\update.ps1"`
   - 開始場所: `H:\ClaudeCode\recipe-search`

クォータ消費は1回あたり約21ユニット（無料枠は1日10,000）なので、毎日実行しても問題ありません。

なお YouTube API の Developer Policies では、取得したデータは原則30日以内にリフレッシュすることが求められています。定期実行はこの点でも合理的です。

### 4. アプリを開く

```powershell
npx serve .
```

表示された `http://localhost:3000` を開くと `videos.json` が自動で読み込まれます。

`index.html` をダブルクリックで直接開く方法もありますが、`file://` では fetch が使えないため毎回 `videos.json` のドラッグ＆ドロップが必要です。

## 検索のしかた

検索窓にワードを入力して **「検索」ボタン**または **Enter** で追加します。いくつでも追加できます。

- **AND**: 追加したワードをすべて含む動画
- **OR**: いずれかを含む動画
- **Backspace**: 入力欄が空の状態で押すと直前のワードを削除

検索対象は**タイトルと概要欄の全文**です。ひらがな・カタカナ・全角半角・記号の違いは無視されるので、「ネギ」でも「ねぎ」でもヒットします。

ヒットした箇所はカードの抜粋とハイライトで確認できます。カードの「概要欄」ボタンで全文が読めます。

並び順の既定は**新しい順**です。関連度順は用意していません。食材ひとつで検索して並び替えが要るほど大量にヒットすることは想定しにくく、AND検索では全件が同じスコアになって新しい順と変わらないためです。

### 精度が足りないときは

全文検索なので、材料に使っていない動画も引っかかります。

- 「ショート動画」は **含める / 除く / のみ** の3択。既定は **除く**（レシピ動画に寄せるため）
- 除外ワードを足す（例: `豚バラ` `-まとめ`）
- ワードを具体的にする（`油` より `ごま油`）

### お気に入り・メモ

- サムネイル右上の ☆ でお気に入り登録

## videos.json のかたち

```jsonc
{
  "generatedAt": "2026-08-03T...",
  "channelId": "UCYkW8AbG82KUsh8zGWARriA",
  "channelTitle": "とにかく売れたい中華料理屋",
  "videoCount": 284,
  "videos": [{
    "videoId": "...",
    "title": "...",
    "url": "https://www.youtube.com/watch?v=...",
    "thumbnail": "...",
    "publishedAt": "...",
    "durationSec": 512,
    "viewCount": 294918,
    "description": "概要欄の全文（無加工）"
  }]
}
```

配列だけの JSON（`[{...}, {...}]`）も読み込めます。

### 他のチャンネルで使う

```bash
node fetch-videos.mjs --channel UCxxxxxxxx --out other.json
```

## 公開する場合の注意

個人利用を前提にしています。公開する場合は以下を確認してください。

- **チャンネル運営者の許可** — 概要欄の材料リストは著作物として保護され得ます
- **YouTube API の利用規約** — Developer Policies ではデータの保存期間（原則30日以内にリフレッシュ）や動画リンクの表示が定められています
- **表示のしかた** — 概要欄を全文掲載せず検索インデックスとして使い、実際のレシピは動画へ誘導する形が無難
# ohtaki-recipe-search
